External images — manual demo

Loads real cross-origin images. A cross-origin image can only be painted onto a readable canvas when it is fetched with CORS. The modes below show the options:

  • ?useCORS — load each external image with crossOrigin="anonymous". Works when the host sends CORS headers (both demo hosts do). Canvas stays readable. This is the recommended approach.
  • ?resolver — intercept every external URL via imageResolver, fetch it client-side and feed html2canvas a base64 data URL. Also keeps the canvas readable, but requires an extra fetch per image. Use it when a host does not send CORS headers.
  • ?allowTaint — draw external images without CORS. The image appears, but the canvas becomes tainted (unreadable): toDataURL()/getImageData() throw, so the capture cannot be exported. Shown here only to illustrate the trade-off.
  • none — no cross-origin handling: external images render blank. Expected.

Active options:  ·  switch: ?useCORS ?allowTaint ?resolver none
